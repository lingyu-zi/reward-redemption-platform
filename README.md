# Reward Redemption Platform

Spring Boot backend system for managing customers, rewards accounts, reward catalogs, redemption carts, and reward redemptions.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Flyway
- MapStruct
- Lombok
